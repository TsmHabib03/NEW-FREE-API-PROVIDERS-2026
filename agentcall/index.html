02 · Modes

Choose how your agent shows up.

Three ways to participate — voice only, full video with a custom webpage as the bot's face, or audio plus screenshare.

Audio

Voice-only presence. Your agent hears everything and speaks when it has something to say. Clean and lightweight.

Webpage A/V

Webpage A/V + Screenshare

10 · FAQ

Common questions.
Straight answers.

What is AgentCall?
AgentCall is a skill for AI agents — it lets any agent (Claude Code, Cursor, Codex, Gemini, Windsurf, Junie, OpenClaw, and more) join video meetings on Google Meet, Zoom, and Microsoft Teams. The agent listens, speaks at the right moments, shares screens, and collaborates — just like a real teammate.
Which meeting platforms are supported?
AgentCall supports Google Meet, Microsoft Teams, and Zoom. The same API works for all three — just pass the meeting link.
How does the agent know when to speak?
The agent calls tts.speak with what it wants to say; the bridge handles timing. Voice intelligence waits for natural pauses, listens for the agent's name (collaborative mode), prevents barge-in by waiting for silence, and cuts the audio within ~1.5s if someone talks over the agent — tagging which sentence was interrupted so the agent can recover. You can customize the behaviour at any time by just telling the agent in plain English — wait longer before speaking, only respond when called by name, be more concise, whatever you want — the skill follows the agent's lead.
How can I make the agent respond faster?
Speed and intelligence are a trade-off, and they're set by your AI agent — not by AgentCall. In Claude Code specifically: /thinking low gives faster responses with shallower reasoning, and /fast (on Opus models) speeds up output without downgrading the model. For the highest intelligence with quick response, use /fast on Opus. Other agents (Cursor, Codex, Gemini CLI, etc.) have similar model + mode controls. The model and mode you pick determine the speed and the depth of reasoning — the skill just runs whatever your agent does.
Does it work with agent frameworks like Claude Code?
Yes — AgentCall ships as an AgentSkill that works with Claude Code, Cursor, Gemini CLI, GitHub Copilot, Windsurf, OpenClaw, and 20+ more agent frameworks. Install it as a skill and your agent joins meetings with a single command.
What safety features are included?
Every bot includes auto-leave when alone, silence timeout, configurable max duration, visible bot name in the participant list, host kick control, configurable data retention, and full audit logging.
How much does it cost?
Pay-per-use with no minimums. Free minutes on signup, all features included. Components are billed separately: meeting bot, transcription, voice intelligence, and TTS. Events, chat, and webhooks are free with every call.
What is AgentCall Tunnel?
Tunnel lets your agent expose a local webpage to the internet instantly and securely. Your agent builds a UI on localhost; AgentCall makes it accessible via HTTPS with a random subdomain; the meeting bot loads it as its video feed. The tunnel is destroyed when the call ends, with a 24-hour safety net.
