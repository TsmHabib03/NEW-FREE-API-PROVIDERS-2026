A practical guide to using compatible API gateways with Claude Code and Codex CLI.

Learn the moving parts, set up a provider, switch between coding agents, and keep your credentials out of public code.

Start Claude Code guide Start Codex guide
request-flow.txt
01 # a coding agent sends a request
client => gateway
02 # the gateway maps it to a model
gateway => provider/model
03 # response returns through the same path
model => client
Provider pricing, credits, models, endpoints, and availability can change. Verify current details in the provider dashboard before configuring a client.

01 / Foundations

What is an API gateway?

A gateway gives a local coding tool one stable API address while handling authentication and model routing behind it.

Claude Code
or Codex CLI
API gateway
base URL + token
Model provider
model ID + quota
API keyA secret token used to authenticate requests.
Base URLThe root address where a client sends API requests.
Model IDThe exact model name accepted by the provider.
Compatible APIAn endpoint that follows an Anthropic or OpenAI request shape.
/v1/modelsList available models
/v1/messagesAnthropic-style messages
/v1/responsesOpenAI Responses API

New API's app documentation describes the common setup inputs as an API address, API key or token, and model name. Read the source documentation

04 / Codex CLI

Configure Codex CLI

Codex CLI uses an OpenAI-compatible flow. The exact configuration keys depend on the Codex version installed on your machine.

CodexCompatible gatewayProvider model

Check the installed version

PowerShell
codex --version

Open the documentation for that version before editing a global configuration file.

Example only

config.toml
# EXAMPLE ONLY
# Verify the schema for your Codex version.

[model_providers.example]
name = "Example Provider"
base_url = "https://provider.example/v1"
env_key = "EXAMPLE_API_KEY"
Confirm the gateway supports the interface required by Codex.

07 / Security

Keep API keys private

Static frontend code is public. Treat every API token as a secret and keep it in your shell, a secret manager, or an approved local CLI configuration.

Never publish
const API_KEY = "sk-xxxxxxxx";

Do not put keys in HTML, JavaScript, GitHub, screenshots, chat messages, or public forums.

Use instead
  • Environment variables
  • Secret managers
  • Provider CLI configuration
  • Local machine credentials

Do not store keys in browser localStorage when a safer local option exists.

08 / Troubleshooting

Fix common API errors

401

Unauthorized

Check the token, Authorization header, expiry, and selected provider.

403

Forbidden

Check account permissions, model access, provider restrictions, and quota.

404

Not found

Check the base URL, the /v1 path, endpoint compatibility, and model ID.

MODEL

Model not found

Run /v1/models and compare the exact returned model ID.

CLAUDE

Wrong Claude route

Check $env:ANTHROPIC_BASE_URL and restart Claude Code after changing it.

CODEX

Wrong Codex provider

Check the active Codex provider configuration and restart Codex.
