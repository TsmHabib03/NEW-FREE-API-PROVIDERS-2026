## Scope and evidence limits

Research used each stored referral destination and homepage, public provider status/pricing endpoints, published documentation, selected frontend text/software markers, valid logo hashes, and official package/repository metadata where available. The original inventory had **57 listed live and 17 already disabled** records. These directory statuses are historical/owner records, not results of inference tests.

| Public check | Results |
|---|---|
| Homepage | 65 HTTP 200; one 526 SSL error; one 530 Tunnel error; one 403 challenge; four connection/timeout failures; two records without URLs |
| Exact stored referral link | 62 HTTP 200; one 526; one 530; two 403; one 404; five connection/timeout failures; two without URLs |
| Software identity | 26 New API/One API status-confirmed records; four Sub2API frontend-marked records |
| Authenticated signup / inference / billing | Not tested |

The 200 responses include SPA shells, redirects, and pages from already disabled services. A catalog entry means the provider publishes that model/route; it does not demonstrate access, model identity, successful inference, latency, or uptime. Public free offers below are **provider-documented claims**, with conditions recorded; no credit was redeemed. Browser UI inspection was unavailable, so there is no screenshot-confirmed visual comparison.

The audit does not independently establish the operators, legal ownership, upstream contracts, or model authenticity for the smaller gateways. It gives stronger grounds for categorization and provisional ranking, not a claim that every reachable service has been proven genuine. Raw public HTML, API responses, and downloaded scripts were read as text; provider code was not executed. Sources and UTC timestamps are recorded per row. GoRouter and TaBi have no source URL in the inventory, so their current services could not be reliably identified.

## Ranking recommendation

Use **service type first**, then offer value/clarity and evidence within each type. Keep PixRouter first as an owner pin. Prioritize clear recurring offers, then explicit signup trials and conditional offers. Put paid/free-unconfirmed gateways in their own section; put empty catalogs, errors, migration/auth issues, and inconsistent claims in review. Separate installed coding products and cloud apps/resources.

No comprehensive independent reputation or common-model performance dataset was found in this audit. Official source quality and public package history are useful signals: Qoder and ZCode have official product docs; FREE-PI's npm version was 0.6.22 and linked MIT repository had 69 stars/16 forks; OmniRush's official GUI repository had 5,037 stars/144 forks and recent activity. These are dated public visibility proxies, not user counts, performance scores, or proof of usable inference. UTIM's npm metadata points to a GitHub repository that returns 404; this may mean private/missing, not fake.

The plan avoids numeric quality scores. A definitive cheapest/fastest ranking would require matching model identity/routes, input/output/cache accounting, currency, tier/window conditions, and successful measured requests. Unmeasured metrics and unverified operators remain unknown.
